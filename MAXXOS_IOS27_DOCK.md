# MaxxOS Launcher3 — iOS 27 Dock

Optional iOS 27-inspired floating dock and search-bar presentation. Both options are off by default.

Settings → Launcher → Home: enable **iOS 27 style floating dock** and/or **iOS 27 style search bar**.

The normal Launcher3 QSB provider remains responsible for search; this change only changes the presentation.

Commit message: `MaxxOS: Add optional iOS 27 style dock and Google search bar`
